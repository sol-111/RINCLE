noteのSEO実態

強さの実態

  • ドメイン評価が高く、公開直後でも検索流入が得られやすい。自社サイトより早く順位がつくケースもある
  • 会員数777万人（2024年時点）・膨大な記事数で「専門性・情報量のあるドメイン」と評価されている

限界

  • HTMLタグ・構造化データ・デザイン・カテゴリ設計のカスタマイズ不可。note内でできるSEO対策はタイトル・ハッシュタグ・本文品質程度
  • 検索評価はすべてnote社のドメインに帰属（無料版・プレミアムでは独自ドメイン不可）。コンテンツはnote社のサービス上にあり、サービス終了時の削除リスクもある
  • noteに置いたリンクは全てnofollow自動付与 — rincle.co.jpへのSEO評価の受け渡しは限定的（人間のクリック流入は普通にある）

note proの現行プラン（2026年6月時点）

  • 基本料金 月80,000円（税抜）・初月無料（2023年3月に5万円→8万円へ改定済み。古い記事の「月5万」は旧料金）
  • 独自ドメイン適用はnote proの標準機能。ただし月8万円はRINCLEの収益規模では予約52件/月分に相当し、現段階では割に合わない

Google公式は「サブドメインとサブディレクトリは本質的に同等」という立場ですが、実務ではサブディレクトリ優位の報告が根強く、国内SEO各社も「同じ事業のブログはサブディレクトリ」を推奨。RINCLEは現状インデックス2〜3ページの弱小ドメインなので、評価を分散させるサブドメインを選ぶ理由がありません。

Bubble本体との同居は技術的に可能

Cloudflare Workerのリバースプロキシ（パスルーティング）で実現可能。Bubble本体はそのまま、rincle.co.jp/blog/* へのアクセスだけ外部ブログに振り分ける構成で、Ghost CMS+Bubbleの完全手順ガイドやBubble公式フォーラムの成功事例が複数あります。seo-setup-guideのPhase 2（Cloudflareフロント導入）と同じ土台なので、既存ロードマップと整合します。

注意: BubbleのCloudflare移行により、DNSがAレコードだとWorkerがバイパスされる報告あり → rincle.co.jpのDNS構成の技術検証が必要（未確認事項#1）。

「ヘッドレスCMS+静的サイト」とは

聞き慣れない構成なので、3つの部品の役割で説明します。要は「記事を書く場所」と「それをWebページとして配信する仕組み」を、軽くて速くて無料の部品で組む構成です。

部品役割
microCMS
ヘッドレスCMS		記事を書く・管理する管理画面。書いた内容はAPI経由で取り出せる。非エンジニアでも投稿できる
Astro
静的サイトジェネレーター		microCMSの記事を引っ張って、HTMLページを"前もって"組み立てるツール
Cloudflare Pages出来上がったHTMLを無料で配信する置き場（ホスティング）
  • ヘッドレス = CMSに表示画面(head)を持たせず、管理画面とデータだけ提供する形。表示は別の道具に任せるので見た目を自由に作れる
  • 静的(static) = アクセスのたびにページを生成せず、先に作っておいたHTMLをそのまま返す方式。だから速く、サーバー側で動くプログラムが無い＝保守・セキュリティ対応がほぼ不要

金額はどちらも誤差レベル（月0〜1,100円）。差が出るのは保守の手間と表示速度。ただし「クライアント自身が記事を書く」方針のため、書きやすさ・自走のしやすさを優先してWordPressを採用（2026-06-19更新）。保守は弊社が準委任で持つため弱点は吸収でき、表示速度はキャッシュ等で実用域に上げる。

RINCLEへの推奨・始め方

  1. 地域×コース記事（SEO資産）= 自社サブディレクトリ一択: rincle.co.jp/blog/ にブログを同居。CMSはWordPressを第一候補（クライアントが自分で書く方針のため／保守は弊社が準委任で対応）。microCMS+静的は弊社運用・速度最優先なら次点
  2. note = 無料版で拡散・ブランド用に限定: 運営の想い・アクティブ店舗のストーリー・イベントレポ。記事末尾からrincle.co.jpへ誘導。本体トピックス欄にnoteサムネイルを置く案はこの用途で有効
  3. 同じ記事を両方に置かない（重複コンテンツ回避）。KWを狙う記事は自社側だけ
  4. 順序: DB再構築完了 → SEO基盤一式（#21-22）→ Cloudflareフロント → サブディレクトリブログ構築。記事の書き溜めは今日から可能（原稿化しておきCMS完成後に一括投入）。noteは即日開始できる
  5. 優先KW: 最優先「観光ルート名×レンタサイクル」（しまなみ海道・ビワイチ等）、次点「都市名×ロードバイク レンタル」。1本目は加盟店が実在する地域（例: 神戸）から。記事テンプレ1種（コース概要・マップ・立ち寄りスポット・レンタル導線）を設計して量産
