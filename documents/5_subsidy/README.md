# 5_subsidy — 補助金

RINCLE（PEDALSTANDARD社）向けの補助金・助成金関連資料の置き場。

## 想定する中身

- 候補となる補助金の調査メモ（対象要件・補助率・上限・公募期間）
- 申請書類のドラフト・提出済み書類
- 事業計画・見積など申請に添える資料
- 採択後の実績報告・交付申請に関する資料

## 運用メモ

- 公募要領など外部資料の原本は `99_ receives/` と同様に原本のまま保存し、要約はmdに残す
- 金額・数値は `4_growth/01_strategy/revenue-model.xlsx` と整合を取ること（出典は「出典と経緯」シートに残す）
