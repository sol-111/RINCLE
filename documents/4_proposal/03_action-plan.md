## 0. 市場概況 — なぜ今このサービスに投資すべきか

### サイクルツーリズム市場
- 日本のサイクルツーリズム市場: 2024年に約63.4億ドル → 2033年までに164億ドル（年平均成長率 11.4%）
- グローバルサイクルツーリズム市場: 2025年に1,292億ドル（年平均成長率 6.8%）
- 出典: Mordor Intelligence / Grand View Research

### E-Bike市場
- グローバルE-Bike市場: 2025年に575億ドル → 2034年までに1,932億ドル（年平均成長率 14.4%）
- 日本国内でもE-Bike販売台数は毎年増加傾向。初心者・シニア層の取り込みに直結
- 出典: Fortune Business Insights

### 国内のスポーツバイクレンタル市場
- 市場規模の公的データはまだ少ないが、しまなみ海道・琵琶湖等の主要サイクリングルートでは需要が急増
- 競合調査の結果、参入企業は全て小規模（最大でもCycleTrip BASEの300台/3店舗）。大手プラットフォーマーが不在の空白市場
- インバウンド訪日客のアクティビティ需要も追い風（2025年の訪日外国人数は過去最高を更新）

### RINCLEにとっての意味
- 成長市場（年10%以上）に、大手プラットフォーマーがまだいない
- 競合は全て自社保有型で、スケーラビリティに限界
- プラットフォーム型のRINCLEが先にポジションを取れば、市場成長の恩恵を最大限受けられる

| # | サービス | モデル | 規模 |

### 結論

- **競合5社は全て自社保有型**。在庫リスクなしのプラットフォーム型はRINCLEだけ
- CycleTrip BASEが最大の直接競合だが、7年で3店舗。RINCLEは3ヶ月で24店舗（スケーラビリティで圧倒）
- 業界全体でデジタル体験（検索/比較/レビュー/アプリ）が未成熟。先に作れば勝てる
- 競合の優位性・弱み・RINCLEとの1対1比較・SWOT分析は [01_competitive-analysis.md](01_competitive-analysis.md) を参照

## 2. 現状の致命的問題

> 詳細: [02_current-issues-and-solutions.md](02_current-issues-and-solutions.md)（ファネル分析・技術課題）
> SEO設定手順: [04_seo-setup-guide.md](04_seo-setup-guide.md)

### SEOが壊滅的

Googleに認識されているページがたった2ページ。主要キーワード（「スポーツバイク レンタル」「ロードバイク レンタル 神戸」等）で全て圏外。**検索からの流入がほぼゼロの状態。**

原因は2つ:
1. **SEO基本設定が未実施**: titleタグ/meta description/OGP/sitemap/h1が全て未設定
2. **Bubble.ioの構造問題**: ページ内容がJavaScriptで後から読み込まれるため、Googleのロボットが「中身が空っぽ」と判断してしまう

→ 各SEO用語の意味と設定手順は [04_seo-setup-guide.md](04_seo-setup-guide.md) に詳しくまとめています

## 3. 成長の好循環（フライホイール）

RINCLEの成長は、以下のサイクルが回ることで加速する。

```
ショップが増える → 選べる車種・エリアが増える
    ↓
ユーザーが増える → 予約が増える
    ↓
レビューが溜まる → 信頼が生まれる
    ↓
さらにユーザーが増える → ショップの売上が上がる
    ↓
ショップが離脱しない + 新規ショップが参加する
    ↓
ショップが増える → ...(繰り返し)
```

**今、止まっているところ: 「ユーザーが来ていない」**
- ショップは24店舗ある（供給側はOK）
- でもSEOが壊滅でGoogle検索からの流入がほぼゼロ（需要側が来ない）
- だからレビューも溜まらず、ショップも「RINCLEに参加して効果あったの？」が分からない

**→ まず「ユーザーを連れてくること」が最優先。UIを磨くのはその次。**

## 3.5. ターゲットペルソナ

RINCLEの主要ターゲットを4つのペルソナで定義する。

### ペルソナA: スポーツバイクデビューの会社員
- 属性: 30代男性、都市部在住、会社員
- 動機: 「ロードバイクに興味あるけど、いきなり30万円は出せない。まず試してみたい」
- 利用シーン: 週末に近場のサイクリングロードで初体験
- 求めるもの: 初心者でも安心なサポート、分かりやすい料金、手ぶらで行ける手軽さ
- RINCLEの提供価値: プロショップスタッフの対面サポート + 気に入ったらその場で購入相談

### ペルソナB: 旅先でサイクリングを楽しみたい旅行者
- 属性: 40代夫婦、観光旅行中
- 動機: 「しまなみ海道をサイクリングしたい。でも自転車を持っていくのは面倒」
- 利用シーン: 旅行先で1日レンタルして観光サイクリング
- 求めるもの: 旅行先の近くに店舗がある、おすすめルートの情報、E-Bikeで体力の差をカバー
- RINCLEの提供価値: 全国24店舗のネットワーク + ショップスタッフ監修のルート情報

### ペルソナC: 購入前にいろいろ試したい経験者
- 属性: 20〜30代男性、クロスバイクは持っている
- 動機: 「次はロードバイクが欲しいけど、ブランドやモデルが多すぎて決められない。実際に乗ってから選びたい」
- 利用シーン: 購入候補のバイクを週末ごとにレンタルして比較試乗
- 求めるもの: 多ブランドの選択肢、スペック比較、購入時のレンタル料金割引
- RINCLEの提供価値: マルチブランド対応 + プロショップでそのまま購入相談 + レンタル料金割引

### ペルソナD: 健康目的のシニア層
- 属性: 50〜60代、体力に自信がない
- 動機: 「健康のために運動したいけど、ランニングは膝が心配。E-Bikeなら続けられそう」
- 利用シーン: 近所のサイクリングロードで定期的にE-Bikeレンタル
- 求めるもの: E-Bike、体力に合ったコース、安全サポート
- RINCLEの提供価値: E-Bike対応ショップ + 初心者向け操作説明 + おすすめルート

## 4. 提案: 実行フェーズ

### Phase 1: 計測 + SEO基盤整備（今週）

> 各項目の設定手順は [04_seo-setup-guide.md](04_seo-setup-guide.md) を参照

| # | 施策 | 何をするか | 工数 |
|---|------|----------|------|
| 1 | **GA4導入** | サイト訪問者の行動を記録開始。離脱ポイントが分かるようになる | 30分 |
| 2 | **title / description設定** | 全ページにGoogleの検索結果に表示されるタイトルと説明文を設定 | 1〜2日 |
| 3 | **OGP設定** | LINEやSNSでリンクを貼ったときにカード表示されるようにする | 同上 |
| 4 | **sitemap.xml + robots.txt** | Googleに全ページの存在を教える | 半日 |
| 5 | **Search Console登録** | Googleにサイトを申請し、インデックス登録をリクエスト | 1時間 |
| 6 | **h1 / alt / canonical** | 各ページの見出し・画像説明・正式URLを設定 | 1〜2日 |

### Phase 2: データ取得 + デザイン改善設計（1〜2週間）

GA4でBeforeデータを取得しつつ、改善案を設計する。

**取得すべきデータ:**
- 月間サイト訪問数 — 何人来ているか
- 流入元 — Google検索/SNS/URLの直接入力/他サイトからのリンク、どこから来ているか
- ページ別離脱率 — どのページで「もういいや」と閉じているか
- 予約完了率 — 予約フローに入った人のうち、何%が最後まで完了したか

**並行して設計する改善案:**
- デザイン全体のリニューアル方針
- 検索バー / 料金の明示 / キャンセルポリシー / 「はじめての方へ」ページ

### Phase 3: UI/UX改善着手（データ取得後）

> 各施策の技術的な詳細・UIモックは [02_current-issues-and-solutions.md](02_current-issues-and-solutions.md) を参照

データで裏付けた優先順位で改善する。Before/After比較で効果を数値レポート。

**Tier 1: 今月やる（来ても予約できない問題を解消）**

| # | 施策 | 理由 |
|---|------|------|
| T1-1 | 検索バーの実装 | 「探せない」なら予約されない |
| T1-2 | リアルタイム空き表示 | 「空いてるか分からない→離脱」防止 |
| T1-3 | 料金の明示 | 「いくらか分からない→離脱」防止 |
| T1-4 | キャンセルポリシー明示 | 「雨だったら？→予約しない」防止 |

**Tier 2: 来月やる（予約率と信頼性を上げる）**

| # | 施策 | 理由 |
|---|------|------|
| T2-1 | 空き状況の一覧比較 | 複数店舗を横並び比較。プラットフォームならではの体験 |
| T2-2 | 自転車の比較機能 | 「どれがいいか分からない」離脱防止 |
| T2-3 | レビューシステム | 信頼の根拠。業界全体でレビューが少ないから先行者利益 |
| T2-4 | SEOランディングページ | Bubble.ioの限界を補う検索用の別ページ（例:「神戸でロードバイクをレンタル」） |
| T2-5 | 店舗詳細ページの充実 | 写真/スタッフ/ルート/レビューで「行きたい」を生む |
| T2-6 | 初心者おすすめ診断 | 3問で最適車種を提案。競合ゼロの機能 |
| T2-7 | 初心者/経験者モード | 表示情報の切替で両方の予約率を最大化 |

**Tier 3: 3ヶ月以内にやる（リピートと成長のエンジン）**

| # | 施策 | 理由 |
|---|------|------|
| T3-1 | 「似た自転車」レコメンド | 満車・予算オーバーでの離脱を代替案で防ぐ |
| T3-2 | お気に入り保存+空き通知 | 初回離脱ユーザーを取り戻す |
| T3-3 | LINE連携 | メールより開封率3倍。リピート最強チャネル |
| T3-4 | 予約後体験の設計 | 天気/ルート/リマインド/QRチェックイン |
| T3-5 | 返却後フォロー | サマリー/次回提案/購入導線/クーポン |
| T3-6 | ショップ向けダッシュボード | 売上可視化→継続率UP→新規ショップ営業の武器 |
| T3-7 | 会員ランク制度 | ペナルティなし、使うほど得する |

### Phase 4: 集客（サイトの穴を塞いでから）

| # | 施策 | 理由 |
|---|------|------|
| 1 | SEOランディングページ | 広告費ゼロで継続的に集客 |
| 2 | Google広告（リスティング） | 「スポーツバイク レンタル ○○」は競合が少なく低単価で取れる可能性 |
| 3 | パートナーショップの既存チャネル活用 | 各ショップのSNS/Web/店頭POPにRINCLE導線。広告費ゼロ |
| 4 | Instagram/X運用開始 | 競合も全社弱い。少しの投資で目立てる |
| 5 | 口コミの種まき | 体験モニター募集/ショップ既存顧客にレビュー依頼。目標: 各店舗5件、合計120件 |

## 5. 全体スケジュール

```
Week 1    GA4導入 + SEO基本設定
 ↓
Week 2-3  Beforeデータ取得 + デザイン改善案の設計
 ↓
Week 4-6  Tier 1 改善（検索バー/空き表示/料金明示/キャンセルポリシー）
 ↓
Week 7-10 Tier 2 改善（比較機能/レビュー/SEOページ/初心者導線）
          + Google広告を小さく開始
 ↓
Month 4-6 Tier 3 改善（LINE/リピート設計/ショップダッシュボード）
          + 広告最適化 + ショップ拡大加速
```

## 5.5. KPI目標

Phase 1でベースラインを取得した上で、以下のKPIを追跡する。

| KPI | ベースライン（Phase 1で取得） | Phase 2終了時目標 | Phase 3終了時目標 |
|-----|--------------------------|-----------------|-----------------|
| 月間サイト訪問数 | 要計測 | 現状の2倍 | 現状の5倍 |
| 予約完了率（CVR） | 要計測 | 現状+1% | 現状+3% |
| 月間予約数 | 要計測 | 現状の2倍 | 現状の5倍 |
| レビュー数（累計） | 0件 | 各店舗3件（計72件） | 各店舗5件（計120件） |
| リピート率 | 要計測 | 10% | 20% |
| Googleインデックス数 | 2ページ | 30ページ以上 | 50ページ以上 |
| 主要キーワード検索順位 | 圏外 | 50位以内 | 20位以内 |
| パートナーショップ数 | 24店舗 | 30店舗 | 50店舗 |

※ 具体的な数値目標はPhase 1のベースラインデータ取得後に調整する
