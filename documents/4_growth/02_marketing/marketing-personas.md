## ペルソナA: スポーツバイクデビューの会社員

### 基本情報

| 項目 | 内容 |
|------|------|
| 年齢・性別 | 30代男性 |
| 職業 | 会社員（デスクワーク中心） |
| 居住地 | 都市部（東京/大阪/名古屋/神戸等） |
| 年収 | 400〜600万円 |
| 趣味 | ランニング、カフェ巡り、ガジェット好き |
| 自転車経験 | ママチャリのみ。スポーツバイクは未経験 |

### 心理・動機

- 「ロードバイクかっこいいな。でも30万円は出せない」
- 「いきなり買って合わなかったらどうしよう」
- 「スポーツバイクってどこで借りられるの？」
- 「周りにやってる人いないから、一人で行くの不安」

### どこにいるか（メディア接触）

| メディア | 行動 |
|---------|------|
| **Google検索** | 「ロードバイク 始め方」「スポーツバイク レンタル 〇〇」「ロードバイク 初心者 おすすめ」 |
| **YouTube** | 自転車系チャンネル（けんたさん、サイクルガジェットTV等）を視聴 |
| **Instagram** | #ロードバイク #サイクリング のハッシュタグで写真を見ている |
| **X（Twitter）** | 自転車クラスタのツイートをたまに見る |

### 獲得チャネル（優先順）

| 優先度 | チャネル | 理由 |
|--------|---------|------|
| 1 | **Google広告**（「ロードバイク レンタル ○○」） | 検索意図が明確。「借りたい」人に直接リーチ |
| 2 | **Instagram広告** | ビジュアルで「こんな体験ができる」を訴求 |
| 3 | **SEO**（「ロードバイク 初心者 レンタル」） | 長期的な流入源 |
| 4 | **YouTube広告/タイアップ** | 自転車系YouTuberの動画内で紹介 |

### 刺さるメッセージ

```
× 「全国54店舗のプロショップネットワーク」（サービス側の都合。ユーザーには響かない）※店舗数を24→54に修正（2026-06-11更新）
○ 「30万円のバイク、買う前に1日6,000円で試せる」
○ 「手ぶらでOK。ヘルメットも無料レンタル」
○ 「プロのスタッフが乗り方から教えます」
```

※ 「1日6,000円」は入口価格としては有効だが、実測の平均予約単価は約¥10,200/件（複数日利用が主力）。1日訴求に加え複数日プランの提示も検討（2026-06-11更新）

### CVRが高い導線

```
Instagram広告（ビジュアル）
  → 「初めての方へ」LP
    → おすすめ診断（3問）
      → 最寄りショップの検索結果
        → 空き確認 → 予約（2分で完了）
```

### ハードル（予約を躊躇する理由）と対策

| ハードル | 対策 |
|---------|------|
| 「自分でも乗れるか不安」 | 「初心者でも安心。スタッフが操作を教えます」を明示 |
| 「いくらかかるか分からない」 | 料金シミュレーターで即時表示。「保険込み・追加料金なし」 |
| 「雨だったらどうしよう」 | 「悪天候時は無料キャンセル」を大きく表示 |
| 「一人で行くのが恥ずかしい」 | 利用者レビュー（「一人で行ったけどスタッフが親切で楽しめた」） |

### 2026-06-11時点のデータでの検証状況（2026-06-11追記）

- 【事実】2台予約18% → 「一人で行くの不安」に対し同伴利用が現実の解になっている可能性（推測）
- 【事実】想定居住地のうち東京・名古屋は在庫があるのに予約ゼロ。Aの検証は現状、関西でしかできない
- 【未検証】レビューがゼロのため「利用者レビュー」対策は現時点で実行不可。Google/Instagram経由の流入はGA4設置待ち

| 3 | **Google広告**（観光地×レンタルキーワード） | SEOで上位取れるまでの補完 |

```

```

### どこにいるか（メディア接触）

| メディア | 行動 |

### 獲得チャネル（優先順）

| 優先度 | チャネル | 理由 |
|--------|---------|------|
| 1 | **パートナーショップ既存チャネル** | すでにショップに来ている客。店頭で「RINCLEで試乗できます」が最強 |
| 2 | **SEO**（「Specialized 試乗 〇〇」「ロードバイク レンタル 比較」） | 試乗したいという明確なニーズ |
| 3 | **自転車メディアタイアップ** | CycleSports等に「買う前に試せるRINCLE」の記事広告 |
| 4 | **Google広告**（ブランド名×試乗/レンタル） | 「Specialized レンタル」等のニッチKW |

### 刺さるメッセージ

```
× 「初心者でも安心」（経験者には響かない）
○ 「買う前に、週末ごとに違うブランドを試せる」
○ 「Specialized, TREK, Cannondale。全部乗ってから決めよう」
○ 「レンタル料金分、購入時に割引」
```

### CVRが高い導線

```
ショップ店頭POP「気になるバイク、RINCLEで試乗できます」
  → QRコード → RINCLE車種ページ
    → 比較機能で候補2〜3台を並べる
      → 予約 → 試乗 → 購入相談
```

| ハードル | 対策 |
|---------|------|
| 「スペックが分からない」 | 経験者モードでコンポ/重量/フレーム素材を全表示 |
| 「自分のサイズがあるか不安」 | サイズガイド + 事前身長入力で推奨サイズ表示 |
| 「買うつもりなのにレンタル料も払うの？」 | 「レンタル料金分を購入時に割引」プログラム |

### 2026-06-11時点のデータでの検証状況（2026-06-11追記）

- 【推測】複数日レンタル主力（平均単価約¥10,200/件）は「週末ごとにじっくり試乗」とも整合し得るが、利用目的データがなく判別不能

```
    → 紹介された友人がRINCLEで初回予約
      → 紹介者に次回500円OFF
```

### ハードル（予約を躊躇する理由）と対策

| ハードル | 対策 |
|---------|------|
| 「レンタルの存在を知らない」 | ショップ店頭POP + スタッフの声かけ |
| 「自分のバイクがあるからレンタルは不要」 | 「友人や家族の分」「別ブランドの試乗」のニーズを喚起 |
| 「ショップで直接借りればよくない？」 | RINCLEの予約システムの利便性（24h予約可・空き確認・決済完了） |

### 2026-06-11時点のデータでの検証状況（2026-06-11追記）

- 【事実】2台予約18%は「友人・家族の分をレンタル」シナリオの実在を示唆
- 【推測】予約上位が神戸17/尼崎12等のショップ立地に集中 → 店頭起点の獲得と整合的だが、予約者が既存顧客かは判別不能
- 【未検証】既存顧客比率・リピート率はリピート率計測（乗車人情報）の整備待ち
