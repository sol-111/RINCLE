# LP vs ブログ記事 — SEO集客にどちらを作るか

## 結論

**SEOで集客するなら「ブログ記事＋本体サイトのエリアページ」。狭義のLP（縦長1ページ・CV特化）はSEO目的では作らない。**

- **狭義のLPはSEOに構造的に弱い**: ①CV特化ページは「有益な情報」として紹介されず被リンクがつきにくい ②1ページではキーワードを網羅できずコンテンツが薄くなる ③検索意図（情報収集）への適合は記事形式が優位（出典: [Web幹事](https://web-kanji.com/posts/landing-page-seo) / [Nobilista](https://co.nobilista.com/ja/column/seo/lp-seo/) / [LANY](https://www.lany.co.jp/blog/lp-seo)）
- **使い分けの定石**: 「どこを走ろう？」と情報収集している段階のユーザー=ブログ記事 / 「今すぐ借りたい」と決まっているユーザー=CVページ（出典: [宮城県よろず支援拠点](https://yorozu-miyagi.go.jp/blog/%E3%80%90%E5%88%9D%E5%BF%83%E8%80%85%E5%90%91%E3%81%91%E3%80%91seo%E8%A8%98%E4%BA%8B%E3%81%A8lp%E3%81%AE%E9%81%95%E3%81%84%E3%81%A8%E3%81%AF%EF%BC%9F%E9%9B%86%E5%AE%A2%E3%81%A8%E5%A3%B2%E4%B8%8A/)）

## RINCLEのKWへの当てはめ

| 狙うKW | 検索意図 | 受け皿 |
|--------|---------|--------|
| 「しまなみ海道 レンタサイクル」「○○ サイクリングコース」 | 情報収集型（どこを走ろう・どう借りよう） | **ブログ記事**（コース紹介+レンタル導線） |
| 「ロードバイク レンタル 名古屋」 | 取引型（借りる場所を探している） | **本体サイトのエリア検索ページ**（#21のsitemap約500URLがまさにこれ=サイト一体型LPに相当）。ブログ記事から内部リンクで流す |
| 広告の受け皿 | — | 狭義の縦長LPが活きるのはここ（action-plan Phase 4のGoogle広告開始時）。SEO目的では不要 |

→ 増永さんの「地域LP」構想は、実体としては**「地域ハブのブログ記事+本体エリアページ」の組み合わせ**で実現するのが、SEO・コスト両面で最も効率的（LP制作の外注費も不要になる）。

## 「ブログ記事＋本体エリアページ」とは具体的に何か（2026-06-18追記）

2種類のページは**ユーザーの段階が違う**と考えると分かりやすい。**「本体エリアページ」は新規に作る別物ではなく、rincle.co.jpの予約サイト側にある既存のエリア検索/店舗一覧ページ**（#21でsitemap化する約500URLがこれ）を指す。

| | ① ブログ記事 | ② 本体エリアページ |
|---|---|---|
| 置き場所 | `rincle.co.jp/blog/`（新設） | `rincle.co.jp` 予約サイト側（既存） |
| 例 | 「神戸の海沿いサイクリングコース完全ガイド」 | 「神戸 ロードバイクレンタル（店舗一覧・空き・予約）」 |
| 見ている人 | 「神戸でどこ走ろう？」=**情報収集段階**（まだ借りると決めてない） | 「神戸で借りられる店どこ？」=**もう借りる気で探している**（取引型） |
| 役割 | **集客**（検索で広く拾う）→ 記事内リンクで②へ送る | **予約の刈り取り**（ここでCV） |

導線のイメージ:

```
検索「神戸 サイクリングコース」（どこ走ろう）
  → ① ブログ記事「神戸の海沿いコースガイド」      ← 集客（網を広げる）
    → 記事内リンク「このコースを走るなら →」
      → ② 本体エリアページ「神戸 ロードバイクレンタル」 ← 予約（刈り取り）

検索「ロードバイク レンタル 神戸」（もう借りたい）
  → ② 本体エリアページに直接着地 → 予約
```

**なぜ2つに分けるか**: 「借りたい」人だけ狙うと母数が小さい。ブログで「まだ迷っている・情報を集めている人」まで入口を広げて本体エリアページに流し込むと予約母数が増える。しかも「コースガイド」型の記事は他サイトからリンクされやすく、狭義LPが弱かった点（被リンク・情報量・検索意図）をそのまま解消する。**ブログ＝集客の網を広げる係／本体エリアページ＝予約させる係**の役割分担。
