## 1. 実行フェーズ

### Phase 1: 計測 + SEO基盤整備 + 即効集客（今週〜2週間）

> 各項目の設定手順は [../03_seo/seo-setup-guide.md](../03_seo/seo-setup-guide.md) を参照
> 即効集客施策（#8〜10）の背景・ROI評価は [../02_marketing/marketing-channels.md](../02_marketing/marketing-channels.md) を参照

| # | 施策 | 何をするか | 工数 |
|---|------|----------|------|
| 1 | **GA4導入** | サイト訪問者の行動を記録開始。離脱ポイントが分かるようになる | 30分 |
| 2 | **title / description設定** | 全ページにGoogleの検索結果に表示されるタイトルと説明文を設定 | 1〜2日 |
| 3 | **OGP設定** | LINEやSNSでリンクを貼ったときにカード表示されるようにする | 同上 |
| 4 | **sitemap.xml + robots.txt** | Googleに全ページの存在を教える（sitemap.xmlは手動生成方式に決定・2026-08-20。手順: [../03_seo/sitemap/sitemap-creation-guide.md](../03_seo/sitemap/sitemap-creation-guide.md)） | 半日 |
| 5 | **Search Console登録** | Googleにサイトを申請し、インデックス登録をリクエスト | 1時間 |
| 6 | **h1 / alt / canonical** | 各ページの見出し・画像説明・正式URLを設定 | 1〜2日 |
| 7 | **クラリティ導入** | セッション録画・ヒートマップで「なぜ離脱するか」を可視化（無料） | 30分 |
| 8 | **パートナーショップ既存チャネル活用** | 24店舗のWeb/SNS/店頭POP/顧客リストにRINCLE導線。素材・テンプレートを用意して配布 | 1〜2日 |
| 9 | **Googleビジネスプロフィール（GBP）対応** | 各店の**同意取得→既存プロフィールにRINCLEを「管理者」として招待→レンタル情報・予約リンクを追記**。同意書テンプレを先に作成。「近くのレンタサイクル」検索に表示 | 設計1日+運用2〜4週間 |
| 10 | **アソビュー/じゃらん掲載（体験プラン化）** | 時間貸しではなく「ルート付き体験プラン」（例: ◯◯絶景ルート半日サイクリング、バイク・ヘルメット込み）として設計し掲載申請。初期費用ゼロ・成果手数料（じゃらん16.4% / アソビュー10〜20% / Klook 15〜20%）。手数料は広告費と捉え、**OTA経由ユーザーのLINE登録→自社リピート引き上げを必ずセット**にする | 1〜2日+審査 |
| 11 | **まとめメディア・自治体観光ページ掲載依頼** | シクロライダー（全国ロードバイク/E-Bikeレンタル一覧）・TABIRINに24店舗の掲載打診、各店舗所在自治体の観光ページにも依頼。**無料・即日着手可**で被リンク+指名流入になる | 1〜2日 |
| 12 | **24店舗の保険・免責の棚卸し** | 各店の保険加入状況を確認。一般的な施設賠償保険は**利用者の運転ミス事故を補償しない**ため、レンタサイクル専用保険（最大1億円補償、6台で年12,000円。 https://bsc.hprtsa.jp/rental.php ）加入を加盟基準として整備 | 1〜2日 |

> SEO（#2〜6）の効果が出るのは2〜6ヶ月後。その間ユーザーゼロを避けるため、即効性のある#8〜12を同時に実施する。
>
> **#9はGBP規約準拠のため2026-06調査で修正**: 第三者（プラットフォーム事業者）によるプロフィールの無断登録は規約違反（プロフィール/アカウント停止の対象）。RINCLE自体のGBPもオンライン専業のため作成不可。「登録2〜3日」ではなく、ショップ調整込みの2〜4週間の継続オペレーションとする。出典: https://support.google.com/business/answer/13763036?hl=ja / https://support.google.com/business/answer/3038177?hl=ja

### Phase 2: データ取得 + デザイン改善設計（1〜2週間）

GA4でBeforeデータを取得しつつ、改善案を設計する。

**取得すべきデータ:**
- 月間サイト訪問数 — 何人来ているか
- 流入元 — Google検索/SNS/URLの直接入力/他サイトからのリンク、どこから来ているか
- ページ別離脱率 — どのページで「もういいや」と閉じているか
- 予約完了率 — 予約フローに入った人のうち、何%が最後まで完了したか

**並行して設計する改善案:**
- デザイン全体のリニューアル方針
- 検索バー / 料金の明示 / キャンセルポリシー / 「はじめての方へ」ページ

### Phase 3: UI/UX改善着手（データ取得後）

> 各施策の技術的な詳細・UIモックは [current-issues-and-solutions.md](current-issues-and-solutions.md) を参照
> UI/UXの参考サービスは [ui-ux-reference-catalog.md](ui-ux-reference-catalog.md) を参照

データで裏付けた優先順位で改善する。Before/After比較で効果を数値レポート。

**Tier 1: 今月やる（来ても予約できない問題を解消）**

| # | 施策 | 理由 |
|---|------|------|
| T1-1 | 検索バーの実装 | 「探せない」なら予約されない |
| T1-2 | リアルタイム空き表示 | 「空いてるか分からない→離脱」防止 |
| T1-3 | 料金の明示 | 「いくらか分からない→離脱」防止 |
| T1-4 | キャンセルポリシー明示 | 「雨だったら？→予約しない」防止 |

**Tier 2: 来月やる（予約率と信頼性を上げる）**

| # | 施策 | 理由 |
|---|------|------|
| T2-1 | 空き状況の一覧比較 | 複数店舗を横並び比較。プラットフォームならではの体験 |
| T2-2 | 自転車の比較機能 | 「どれがいいか分からない」離脱防止 |
| T2-3 | レビューシステム | 信頼の根拠。業界全体でレビューが少ないから先行者利益 |
| T2-4 | SEOランディングページ | Bubble.ioの限界を補う検索用の別ページ。**最優先は「観光ルート名×レンタサイクル」**（例:「しまなみ海道 レンタサイクル」「ビワイチ レンタサイクル」。しまなみだけで年間17.3万台の実需。 https://prtimes.jp/main/html/rd/p/000000561.000026884.html ）、次点で「都市名×ロードバイク レンタル」（2026-06調査でKW優先順位を再編） |
| T2-5 | 店舗詳細ページの充実 | 写真/スタッフ/ルート/レビューで「行きたい」を生む |
| T2-6 | 初心者おすすめ診断 | 3問で最適車種を提案。競合ゼロの機能 |
| T2-7 | 初心者/経験者モード | 表示情報の切替で両方の予約率を最大化 |
| T2-8 | E-Bikeの独立カテゴリ化 | E-Bike専用KW群/LP/OTAプランを立てる。E-Bikeレンタルは前年比+40%成長・販売台数はママチャリ超えの成長領域で、供給側対応が薄いうちに先行する（2026-06調査で追加。 https://www.atpress.ne.jp/news/3773939 ） |

**Tier 3: 3ヶ月以内にやる（リピートと成長のエンジン）**

| # | 施策 | 理由 |
|---|------|------|
| T3-1 | 「似た自転車」レコメンド | 満車・予算オーバーでの離脱を代替案で防ぐ |
| T3-2 | お気に入り保存+空き通知 | 初回離脱ユーザーを取り戻す |
| T3-3 | LINE連携 | メールより開封率3倍。リピート最強チャネル |
| T3-4 | 予約後体験の設計 | 天気/ルート/リマインド/QRチェックイン。**電子免責同意を統合**（Smartwaiver型: 事前オンライン署名+店頭QR署名、月額$15〜。 https://www.smartwaiver.com/ ）し受付30分問題を同時に解消。免責文言は全店共通テンプレをRINCLEが提供 |
| T3-5 | 返却後フォロー | サマリー/次回提案/クーポン。購入導線は単なるリンクではなく**「試乗履歴つき購入相談予約」**（借りた車種・サイズ・感想をショップに引き継ぐ）として実装し、物販送客を第2収益源に。Trekは「レンタル料100%を購入代金に充当」を標準特典化（ https://www.trekbikes.com/us/en_US/trek-bike-rentals/ ）、レンティオはレンタル経由で購入数4倍以上の実績（2026-06調査で具体化） |
| T3-6 | ショップ向けダッシュボード | 売上可視化→継続率UP→新規ショップ営業の武器。**先行施策として「月次送客レポートメール」をPhase 2からGA4+予約データで手動実装**し、開発完了を待たずに送客実績を毎月証明する（離脱防止+営業資料を兼ねる） |
| T3-7 | 会員ランク制度 | ペナルティなし、使うほど得する |

### Phase 4: 集客（サイトの穴を塞いでから）

| # | 施策 | 理由 |
|---|------|------|
| 1 | SEOランディングページ | 広告費ゼロで継続的に集客 |
| 2 | Google広告（リスティング） | 「スポーツバイク レンタル ○○」は競合が少なく低単価で取れる可能性。**出稿開始と同時にキーワードプランナーで「観光ルート名×レンタサイクル」「都市名×ロードバイク レンタル」「E-Bike レンタル×地域」の実数を取得し、SEO LPの優先順位を確定**する |
| 3 | パートナーショップチャネルの継続強化 | Phase 1で開始済み（#8）。投稿テンプレ更新・新店舗への展開を継続 |
| 4 | Instagram/X運用開始 | 競合も全社弱い。少しの投資で目立てる |
| 5 | 口コミの種まき | ショップ既存顧客・実利用者にレビュー依頼。目標: 各店舗5件、合計120件。**ステマ規制対応で設計修正（2026-06調査）**: 景表法ステマ規制（2023年10月施行）により「割引と引き換えにレビュー」は対価+依頼の事実だけで広告表示義務が発生し、違反は措置命令・課徴金の対象。体験モニターを実施する場合は (a) モニター利用とレビュー依頼を切り離す（投稿は任意・評価内容に条件をつけない）、または (b) 投稿に「モニター利用」である旨の表示を徹底する。「高評価を条件に割引」は明確に違法。出典: https://www.caa.go.jp/policies/policy/representation/fair_labeling/stealth_marketing |

### 並行トラック: 自治体・DMO営業（Phase 3〜、toCマーケと並行）

> 2026-06調査で追加。調査自治体の54.5%がサイクルツーリズム施策を実施、最多施策は「レンタ/シェアサイクルの整備」(35%)だが、ノウハウ・人材不足が課題 — RINCLEが「予約システム+プロショップ網」をパッケージ営業できる非対称性がある。しまなみ海道ではレンタサイクル基軸の活性化が観光庁実証事業に採択済み（ https://kanko-dx.go.jp/wp-content/uploads/2025/02/3bc01f47036d84cccb325cded25a0c07.pdf ）。

| # | 施策 | 内容 |
|---|------|------|
| G1 | 観光協会・DMOサイト掲載 | ナショナルサイクルルート（しまなみ・ビワイチ等）圏の加盟店から、当該観光協会・自治体観光ページへの掲載依頼（無料が多く、信頼性の高い被リンクにもなる） |
| G2 | 共同プレスリリース | 24店舗・12都府県ネットワークを素材にPR TIMES+メディア個別打診 |
| G3 | 実証事業への参画提案 | レンタサイクル事業者単独の補助金は確認できず、**自治体・DMO主体の事業に「参画事業者」として入る**形が現実的 |

## 2. 全体スケジュール

```
Week 1-2  GA4+クラリティ導入 + SEO基本設定
          + 即効集客（ショップチャネル/アソビュー体験プラン/メディア・自治体ページ掲載依頼/保険棚卸し）
          + GBP: 同意取得を開始（管理者招待・情報追記はWeek 4頃まで継続）
 ↓
Week 2-3  Beforeデータ取得 + デザイン改善案の設計 + 月次送客レポートメールの手動運用開始
 ↓
Week 4-6  Tier 1 改善（検索バー/空き表示/料金明示/キャンセルポリシー）
 ↓
Week 7-10 Tier 2 改善（比較機能/レビュー/SEOページ/初心者導線）
          + Google広告を小さく開始
 ↓
Month 4-6 Tier 3 改善（LINE/リピート設計/ショップダッシュボード）
          + 広告最適化 + ショップ拡大加速
```

## 3. KPI目標

Phase 1でベースラインを取得した上で、以下のKPIを追跡する。

| KPI | ベースライン（Phase 1で取得） | Phase 2終了時目標 | Phase 3終了時目標 |
|-----|--------------------------|-----------------|-----------------|
| 月間サイト訪問数 | 要計測 | 現状の2倍 | 現状の5倍 |
| 予約完了率（CVR） | 要計測 | 現状+1% | 現状+3% |
| 月間予約数 | 要計測 | 現状の2倍 | 現状の5倍 |
| レビュー数（累計） | 0件 | 各店舗3件（計72件） | 各店舗5件（計120件） |
| リピート率 | 要計測 | 10% | 20% |
| レンタル→購入相談数（物販送客） | 0件（T3-5実装後に計測） | - | 計測開始・実績作り |
| Googleインデックス数 | 2ページ | 30ページ以上 | 50ページ以上 |
| 主要キーワード検索順位 | 圏外 | 50位以内 | 20位以内 |
| パートナーショップ数 | 24店舗 | 30店舗 | 50店舗 |

※ 具体的な数値目標はPhase 1のベースラインデータ取得後に調整する
※ 2026-08-20注記: KGI/KPI目標は凍結中（実績の月次記録は継続。ユーザー増と差別化実装後に設定）。パートナーショップ数のベースライン24店舗は当時の値で、2026-08-20実測では56店舗
