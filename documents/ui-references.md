# RINCLE UI/UX リファレンス — 類似サービス・業界一覧

> 作成日: 2026-05-19
> 目的: RINCLEのUI/UX設計の参考になるサービスを整理し、各社から何を学ぶかを明確にする

---

## クライアント指定リファレンス

### Honda GO Bike Rental
- URL: https://hondago-bikerental.jp/
- クライアントコメント: 「店舗、バイクのリスト表示、会員登録などみやすくモバイルのUIなどは理想」

**RINCLEと同じ構造のサービス。最も直接的な参考。**
- 全国400店舗以上のHonda販売店ネットワークでバイクレンタル（= プロショップネットワーク型）
- 検索: 都道府県→市区町村→店舗の3段階カスケード + 排気量/車種名フィルタ + 地図/現在地検索
- リスト表示: グリッドレイアウトのカード形式（排気量バッジ/車種画像/車名/説明）
- 料金シミュレーター: 独立5ステップ。クラス→車種→期間→保険→装備でリアルタイム見積
- 予約: 5ステップ（店舗・日時→オプション→情報入力→確認→完了）。プログレスバー明示
- 会員登録: 3ステップ（メアド送信→本登録→完了）。入会金・年会費無料
- 料金表: 6時間プラン×7排気量クラスの明確なマトリクス
- 「はじめての方へ」: 予約→来店→利用→返却の4ステップを図解
- レビュー機能: なし
- レスポンシブ対応（PC/SP出し分け）

**学ぶべきポイント:**
- 料金シミュレーターのリアルタイム見積UI
- 料金表のマトリクス表示（時間×クラス）の明快さ
- 「はじめての方へ」の4ステップ図解
- 保険・補償の比較UI（3シナリオ並列比較）
- 5ステップ予約フローのプログレスバー

## 類似構造のサービス（プラットフォーム型 × 検索・比較・予約）

### 1. たびらいレンタカー — 「コミコミ価格比較」の教科書
- URL: https://www.tabirai.net/car/
- 構造: レンタカー会社のプランを一括比較・予約
- **RINCLEとの類似度: ★★★★★**（複数店舗のレンタル品を横断比較するモデルが完全一致）

**学ぶべきポイント:**
- **コミコミ価格表示**: カーナビ/ETC/免責補償費を込みにした総額表示。隠れたコストがない安心感
- 検索バー: 出発地+返却地+日時のみのシンプル設計
- LINE連携予約（業界初）

### 2. Booking.com — 「予約を後押しする心理設計」の教科書
- URL: https://www.booking.com/
- 構造: 世界最大の宿泊予約プラットフォーム

**学ぶべきポイント:**
- **「残り○室」「○人が閲覧中」の緊急性表示**（スカーシティ + ソーシャルプルーフ）
- **「無料キャンセル可能」の目立つ表示**で予約ハードルを下げる
- レビュー点数をカード上部に配置（一覧での比較判断を助ける）
- 10点満点 + 複数カテゴリ別サブスコアのレビュー設計
- フィルタの充実度（価格帯/施設タイプ/アメニティ等）

### 3. Airbnb — 「写真と感情で選ばせる」UIの教科書
- URL: https://www.airbnb.jp/
- 構造: 個人の物件・体験を予約するプラットフォーム

**学ぶべきポイント:**
- **写真ファーストの大きなカード型UI**（視覚的なサービスに最適）
- **感情的・体験的なカテゴリ分類**（「スゴイ！」「最高の眺め」「ツリーハウス」）→ 機能的分類だけでなく「どんな体験がしたいか」で探せる
- ミニマルな配色（プライマリカラーは5%のみ）で情報を見やすく
- **フローティング予約ボタン**で常時アクセス可能な予約導線
- 下部メニューバー（モバイルの片手操作に最適化）
- ウィッシュリスト（お気に入り保存）

### 4. アソビュー — 「体験を検索する」UIの教科書
- URL: https://www.asoview.com/
- 構造: 日本最大の遊び・体験予約プラットフォーム（640種類/28,000プラン）

**学ぶべきポイント:**
- **「カルーセルより縦並び」のデータドリブン判断**（3件目以降タップされないと判明→縦並びに変更）
- **シーン別カテゴリ**（「子どもとあそべる」「雨でもあそべる」）→ ユーザーの実利用文脈に即した分類
- マップ検索（現在地ベース）
- 電子チケットでシームレスな利用体験

### 5. Klook — 「5ステップ予約フロー」の教科書
- URL: https://www.klook.com/ja/
- 構造: 世界規模の旅行体験・アクティビティ予約

**学ぶべきポイント:**
- **「やりたいこと起点」と「場所起点」の2つの検索導線**
- 5ステップの明快な予約フロー
- **ウィッシュリスト機能**で検討段階のユーザーを確保
- QRコードバウチャーでペーパーレス利用

### 6. じゃらんnet — 「目的別ショートカット」の教科書
- URL: https://www.jalan.net/
- 構造: 国内宿泊・旅行予約

**学ぶべきポイント:**
- **目的別ショートカット**（「ビジネスホテル」「温泉」「高級宿」）→ 「何となく探したい」ユーザーに有効
- **閲覧履歴の活用**（最近見たプランを写真付きバナーで表示）→ 再訪・比較検討の促進
- 「今日泊まれる宿」「近くの宿」など即時ニーズ対応のショートカット

### 7. Anyca — 「C2Cプラットフォームの写真品質管理」の教科書
- URL: https://anyca.net/
- 構造: 個人間カーシェア（DeNA運営）

**学ぶべきポイント:**
- **プロカメラマン無料撮影会をオーナー向けに開催**→ 写真品質の底上げ
- **クイック予約**（即時確定）と通常予約（チャットやり取り）の2モード
- クイック予約対応車を紫ラベルで視覚的に差別化

### 8. VELTRA — 「口コミを35万件集めた仕組み」の教科書
- URL: https://www.veltra.com/jp/
- 構造: 海外・国内のオプショナルツアー予約

**学ぶべきポイント:**
- **写真付き体験談投稿で100ポイント還元**→ UGC促進のインセンティブ設計
- 35万件の体験談が信頼性の源泉
- 高評価から低評価まで透明に掲載

### 9. LUUP — 「マップ中心UI」の教科書
- URL: https://luup.sc/
- 構造: 電動キックボード/自転車シェア

**学ぶべきポイント:**
- **マップ中心UI**（起動直後にマップ→周辺ポートを表示）
- ポートが「ぴょこっと跳ねる」アニメーション（「近くにたくさんある」感の演出）
- QRコード読み取りで即利用開始
- 片手操作前提のUX設計

### 10. HELLO CYCLING — 「マップピンの視認性」の教科書
- URL: https://www.hellocycling.jp/
- 構造: シェアサイクル（16サービス統合）

**学ぶべきポイント:**
- **大きなマップピン**で他情報に埋もれない視認性
- 車種タブ切替でステーション表示を絞り込み
- 16の提携サービスを1アプリで統合（= 複数ショップ統合の設計思想）

## RINCLEへの機能マッピング

| RINCLEの機能 | 最も参考にすべきサービス | 具体的に何を真似るか |
|-------------|----------------------|-------------------|
| **検索バー** | Honda GO / たびらい | エリア+日付+車種のシンプル3要素。Honda GOの3段階カスケード |
| **検索結果リスト** | Airbnb / アソビュー | 写真大きめのカード型。カルーセルではなく縦並び |
| **フィルタ・ソート** | Booking.com | 価格帯/カテゴリ/レビュー評価等のサイドバーフィルタ |
| **マップ検索** | LUUP / HELLO CYCLING | 現在地→最寄りショップ。ピンの視認性デザイン |
| **料金表示** | たびらい / Honda GO | コミコミ価格。Honda GOの料金シミュレーター |
| **空き状況** | Booking.com | 「残り○台」のスカーシティ表示 |
| **比較機能** | たびらい | 横並びプラン比較（= 自転車比較） |
| **予約フロー** | Honda GO / Klook | 5ステップ以内。プログレスバー明示 |
| **レビュー** | Booking.com / VELTRA | 複数軸スコア + 写真付き投稿でポイント還元 |
| **お気に入り** | Airbnb / Klook | ウィッシュリスト + 空き通知 |
| **初心者導線** | Honda GO / アソビュー | 「はじめての方へ」4ステップ図解。シーン別カテゴリ |
| **初心者/経験者** | Airbnb | 感情的カテゴリ（初心者向け）vs スペック表示（経験者向け） |
| **モバイルUI** | Airbnb / LUUP | 下部メニューバー。フローティングCTA。片手操作前提 |
| **写真品質管理** | Anyca | パートナーショップ向け撮影ガイドライン/プロ撮影支援 |

| **LINE連携** | たびらい | LINE予約（業界初を謳う） |
| **口コミ促進** | VELTRA | 写真付き投稿でポイント還元 |
