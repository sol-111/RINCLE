## ペルソナA: スポーツバイクデビューの会社員

### 基本情報

| 項目 | 内容 |
|------|------|
| 年齢・性別 | 30代男性 |
| 職業 | 会社員（デスクワーク中心） |
| 居住地 | 都市部（東京/大阪/名古屋/神戸等） |
| 年収 | 400〜600万円 |
| 趣味 | ランニング、カフェ巡り、ガジェット好き |
| 自転車経験 | ママチャリのみ。スポーツバイクは未経験 |

### 心理・動機

- 「ロードバイクかっこいいな。でも30万円は出せない」
- 「いきなり買って合わなかったらどうしよう」
- 「スポーツバイクってどこで借りられるの？」
- 「周りにやってる人いないから、一人で行くの不安」

### どこにいるか（メディア接触）

| メディア | 行動 |
|---------|------|
| **Google検索** | 「ロードバイク 始め方」「スポーツバイク レンタル 〇〇」「ロードバイク 初心者 おすすめ」 |
| **YouTube** | 自転車系チャンネル（けんたさん、サイクルガジェットTV等）を視聴 |
| **Instagram** | #ロードバイク #サイクリング のハッシュタグで写真を見ている |
| **X（Twitter）** | 自転車クラスタのツイートをたまに見る |

### 獲得チャネル（優先順）

| 優先度 | チャネル | 理由 |
|--------|---------|------|
| 1 | **Google広告**（「ロードバイク レンタル ○○」） | 検索意図が明確。「借りたい」人に直接リーチ |
| 2 | **Instagram広告** | ビジュアルで「こんな体験ができる」を訴求 |
| 3 | **SEO**（「ロードバイク 初心者 レンタル」） | 長期的な流入源 |
| 4 | **YouTube広告/タイアップ** | 自転車系YouTuberの動画内で紹介 |

### 刺さるメッセージ

```
× 「全国24店舗のプロショップネットワーク」（サービス側の都合。ユーザーには響かない）
○ 「30万円のバイク、買う前に1日6,000円で試せる」
○ 「手ぶらでOK。ヘルメットも無料レンタル」
○ 「プロのスタッフが乗り方から教えます」
```

### CVRが高い導線

```
Instagram広告（ビジュアル）
  → 「初めての方へ」LP
    → おすすめ診断（3問）
      → 最寄りショップの検索結果
        → 空き確認 → 予約（2分で完了）
```

### ハードル（予約を躊躇する理由）と対策

| ハードル | 対策 |
|---------|------|
| 「自分でも乗れるか不安」 | 「初心者でも安心。スタッフが操作を教えます」を明示 |
| 「いくらかかるか分からない」 | 料金シミュレーターで即時表示。「保険込み・追加料金なし」 |
| 「雨だったらどうしよう」 | 「悪天候時は無料キャンセル」を大きく表示 |
| 「一人で行くのが恥ずかしい」 | 利用者レビュー（「一人で行ったけどスタッフが親切で楽しめた」） |

## ペルソナB: 旅先でサイクリングを楽しみたい旅行者

### 基本情報

| 項目 | 内容 |
|------|------|
| 年齢・性別 | 40代夫婦 |
| 職業 | 会社員 or 自営業 |
| 居住地 | 全国（旅行先でレンタル） |
| 年収 | 500〜800万円 |
| 趣味 | 旅行、温泉、グルメ、写真 |
| 自転車経験 | 多少あり。しまなみ海道や琵琶湖をサイクリングしたいと思っている |

### 心理・動機

- 「しまなみ海道をサイクリングしたい！でも自転車持っていけない」
- 「旅先で手軽に借りられるところないかな」
- 「夫婦で体力差があるから、E-Bikeがあると嬉しい」
- 「せっかくなら良いバイクに乗りたい」

### どこにいるか（メディア接触）

| メディア | 行動 |
|---------|------|
| **Google検索** | 「しまなみ海道 レンタサイクル」「琵琶湖 ロードバイク レンタル」「〇〇（観光地） サイクリング」 |
| **じゃらん/楽天トラベル** | 宿泊予約のついでに「周辺の体験」を検索 |
| **アソビュー** | 旅先のアクティビティを探している |
| **Instagram** | #しまなみ海道 #サイクリング旅 の投稿を見て「行きたい」と思う |

### 獲得チャネル（優先順）

| 優先度 | チャネル | 理由 |
|--------|---------|------|
| 1 | **アソビュー/じゃらん体験への掲載** | 旅行計画中のユーザーにリーチ。予約導線も完成している |
| 2 | **SEO**（「しまなみ海道 レンタサイクル」等） | 検索ボリュームが大きい観光地×サイクリングキーワード |
| 3 | **Google広告**（観光地×レンタルキーワード） | SEOで上位取れるまでの補完 |
| 4 | **Instagram**（観光地×サイクリングの写真投稿） | 旅行前のリサーチ段階でリーチ |

### 刺さるメッセージ

```
× 「プロショップネットワーク型プラットフォーム」
○ 「しまなみ海道を、プロが整備したロードバイクで走ろう」
○ 「夫婦でも安心。E-Bikeなら体力差をカバー」
○ 「手ぶらで来て、手ぶらで帰れる」
```

### CVRが高い導線

```
Google検索「しまなみ海道 レンタサイクル」
  → 地域別LP（しまなみ海道特集ページ）
    → おすすめルート紹介 + ショップ一覧
      → 空き確認 → 予約
```

```
アソビュー
  → RINCLE体験ページ
    → プラン選択 → 予約
```

### ハードル（予約を躊躇する理由）と対策

| ハードル | 対策 |
|---------|------|
| 「旅行先に店舗があるか分からない」 | マップ検索で即時表示 |
| 「観光とサイクリングの時間配分が不安」 | おすすめルート（距離×所要時間）を提示 |
| 「夫婦の体力差」 | E-Bike対応ショップをフィルタ表示 |
| 「天気が心配」 | 悪天候時無料キャンセルを明示 |

## ペルソナC: 購入前にいろいろ試したい経験者

### 基本情報

| 項目 | 内容 |
|------|------|
| 年齢・性別 | 20〜30代男性 |
| 職業 | 会社員/エンジニア |
| 居住地 | 都市部 |
| 年収 | 400〜700万円 |
| 趣味 | サイクリング（週末ライド）、ガジェット、スペック比較 |
| 自転車経験 | クロスバイク所有。ロードバイクへのステップアップを検討中 |

### 心理・動機

- 「次はロードバイクが欲しいけど、SpecializedとTREKどっちがいい？」
- 「実際に乗ってみないと分からない。試乗できる場所がない」
- 「友達はCannondale推しだけど、自分の体に合うかは別の話」
- 「50万円のバイク、失敗したくない」

### どこにいるか（メディア接触）

| メディア | 行動 |
|---------|------|
| **Google検索** | 「Specialized Allez レビュー」「ロードバイク 比較 2026」「TREK vs Specialized」 |
| **YouTube** | インプレ動画、ロードバイク比較動画を頻繁に視聴 |
| **価格.com/みんカラ的な比較サイト** | スペック比較が好き |
| **X（Twitter）** | 自転車クラスタで情報収集 |
| **CycleSports/BikeClub** | 自転車専門メディアの記事を読む |

### 獲得チャネル（優先順）

| 優先度 | チャネル | 理由 |
|--------|---------|------|
| 1 | **パートナーショップ既存チャネル** | すでにショップに来ている客。店頭で「RINCLEで試乗できます」が最強 |
| 2 | **SEO**（「Specialized 試乗 〇〇」「ロードバイク レンタル 比較」） | 試乗したいという明確なニーズ |
| 3 | **自転車メディアタイアップ** | CycleSports等に「買う前に試せるRINCLE」の記事広告 |
| 4 | **Google広告**（ブランド名×試乗/レンタル） | 「Specialized レンタル」等のニッチKW |

### 刺さるメッセージ

```
× 「初心者でも安心」（経験者には響かない）
○ 「買う前に、週末ごとに違うブランドを試せる」
○ 「Specialized, TREK, Cannondale。全部乗ってから決めよう」
○ 「レンタル料金分、購入時に割引」
```

### CVRが高い導線

```
ショップ店頭POP「気になるバイク、RINCLEで試乗できます」
  → QRコード → RINCLE車種ページ
    → 比較機能で候補2〜3台を並べる
      → 予約 → 試乗 → 購入相談
```

### ハードル（予約を躊躇する理由）と対策

| ハードル | 対策 |
|---------|------|
| 「スペックが分からない」 | 経験者モードでコンポ/重量/フレーム素材を全表示 |
| 「自分のサイズがあるか不安」 | サイズガイド + 事前身長入力で推奨サイズ表示 |
| 「買うつもりなのにレンタル料も払うの？」 | 「レンタル料金分を購入時に割引」プログラム |

## ペルソナD: 健康目的のシニア層

### 基本情報

| 項目 | 内容 |
|------|------|
| 年齢・性別 | 50〜60代、男女問わず |
| 職業 | 会社員（管理職）or 定年退職後 |
| 居住地 | 郊外〜地方都市 |
| 趣味 | ウォーキング、旅行、ガーデニング |
| 自転車経験 | ほぼなし。E-Bikeの存在を最近知った |

### 心理・動機

- 「健康のために運動したいけど、ランニングは膝が心配」
- 「E-Bikeなら坂道もラクらしい」
- 「でもE-Bikeって30万円以上するんでしょ？試してみたい」
- 「一人で行って使い方が分からなかったらどうしよう」

### どこにいるか（メディア接触）

| メディア | 行動 |
|---------|------|
| **Google検索** | 「E-Bike とは」「電動アシスト自転車 シニア」「健康 自転車 おすすめ」 |
| **テレビ/新聞** | 健康特集でE-Bikeが紹介されて興味を持つ |
| **LINE** | 家族やグループLINEで情報を受け取る（メールよりLINE派） |
| **地方新聞/フリーペーパー** | 地元の情報源 |

### 獲得チャネル（優先順）

| 優先度 | チャネル | 理由 |
|--------|---------|------|
| 1 | **パートナーショップ既存チャネル** | 店頭でE-Bikeの試乗を提案。対面の安心感 |
| 2 | **Googleビジネスプロフィール** | 「近くの自転車レンタル」で地図検索 |
| 3 | **地方メディア/PR** | 地元の新聞やフリーペーパーに掲載 |
| 4 | **LINE広告** | シニア層のLINE利用率は高い |

### 刺さるメッセージ

```
× 「マルチブランド対応プラットフォーム」（意味が分からない）
× 「CVR最大化」（もっと分からない）
○ 「膝に優しい。電動アシストで坂道もスイスイ」
○ 「スタッフが乗り方を丁寧に教えます。初めてでも安心」
○ 「まずは1日お試し。気に入ったら購入も相談できます」
```

### CVRが高い導線

```
ショップ店頭で店員が提案
  → 「E-Bikeの試乗、RINCLEで予約できますよ」
    → 店員がその場で予約を手伝う
      → 当日来店 → スタッフが操作説明 → 体験
```

### ハードル（予約を躊躇する理由）と対策

| ハードル | 対策 |
|---------|------|
| 「Web予約が難しそう」 | ショップスタッフが代理予約。または電話予約対応 |
| 「体力が持つか不安」 | E-Bikeのアシスト機能を説明。「平地なら3時間はラクラク」 |
| 「操作が分からない」 | 「スタッフが1から教えます」を明示。事前に操作動画を送信 |

## ペルソナE: プロショップの既存顧客

### 基本情報

| 項目 | 内容 |
|------|------|
| 年齢・性別 | 全年代、男性が多い |
| 職業 | 様々 |
| 居住地 | ショップの近隣 |
| 自転車経験 | あり。すでにスポーツバイクを所有しショップで購入 or 整備で来店 |

### 心理・動機

- 「友達をサイクリングに連れて行きたいけど、友達はバイクを持ってない」
- 「別のブランドやモデルも乗ってみたい」
- 「サイクリングイベントに参加したいけど、今のバイクだと物足りない」
- 「家族（妻/子供）にもサイクリングを体験させたい」

### どこにいるか（メディア接触）

| メディア | 行動 |
|---------|------|
| **ショップ店頭** | 整備や買い物でショップに来店している |
| **ショップのSNS** | ショップのInstagram/Facebookをフォロー |
| **ショップのメールマガジン** | 新商品情報やイベント告知を受け取っている |
| **ライドイベント** | ショップ主催のグループライドに参加 |

### 獲得チャネル（優先順）

| 優先度 | チャネル | 理由 |
|--------|---------|------|
| 1 | **ショップ店頭での声かけ** | 来店時に「友達連れてくるなら、RINCLEでレンタルできますよ」 |
| 2 | **ショップのSNS投稿** | 「レンタルサービス始めました」の告知 |
| 3 | **ショップのメール/LINE配信** | 既存顧客リストに一斉配信 |
| 4 | **グループライドイベント** | 「バイクを持っていない友人も参加OK。RINCLEでレンタルできます」 |

### 刺さるメッセージ

```
○ 「友達も一緒にサイクリング。バイクはRINCLEでレンタルできます」
○ 「Specialized乗ってるけど、TREKも試してみたくない？」
○ 「家族でサイクリング。奥さんにはE-Bikeがおすすめ」
○ 「次のイベント用に、カーボンフレームを1日だけレンタル」
```

### CVRが高い導線

```
来店時にショップスタッフが声かけ
  → 店頭POP or QRコードでRINCLEへ
    → 車種一覧（経験者モード）
      → 比較 → 予約
```

```
ショップのSNS投稿
  → 「友人紹介キャンペーン」
    → 紹介された友人がRINCLEで初回予約
      → 紹介者に次回500円OFF
```

### ハードル（予約を躊躇する理由）と対策

| ハードル | 対策 |
|---------|------|
| 「レンタルの存在を知らない」 | ショップ店頭POP + スタッフの声かけ |
| 「自分のバイクがあるからレンタルは不要」 | 「友人や家族の分」「別ブランドの試乗」のニーズを喚起 |
| 「ショップで直接借りればよくない？」 | RINCLEの予約システムの利便性（24h予約可・空き確認・決済完了） |
