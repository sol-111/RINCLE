01

そもそもスキルとは

サーバー登録も設定画面もない
スキル — 用語
Claude Codeに「この種の仕事はこう進めて」と教える指示書ファイルの束。フォルダを置くだけで登録される。

動く仕組みは3段階。普段は説明文1行分しか場所を取らず、必要な時だけ全部が読み込まれる省エネ構造になっている。

  1. SKILL.mdの説明文（description）だけは常に見えている — どの案件でClaudeを開いても、名刺のように1行だけ提示されている
  2. 該当する依頼が来ると本文が読み込まれる — 「HTML資料を作って」「デザインを統一して」でClaudeが自分でスキルを開く
  3. 残りのファイルは必要な時だけ — 本文に「template.cssとsnippets.htmlを読め」と書いてあるので、作業に入った時だけ読まれる
確実に発動させたい時: チャットで /html-doc-design と打ってから頼む。
02

中身のファイルと役割

何を守るか・どう見えるか・どう書くか
~/.claude/skills/html-doc-design/
├── SKILL.md       # ルールブック（原則11箇条+ページ構造+スライド規格）
├── template.css   # 核部品のCSS（コピーして使う。色の差し替えは:rootだけ）
├── parts.css      # 拡張部品42種のCSS（ボタン・モーダル・かんばん等。必要な時だけ）
├── snippets.html  # 各部品のHTML雛形集（コピーして使う）
├── gallery.html   # 全部品の見本（見た目の正本。ブラウザで開いて確認）
├── guide.html     # このページ（人間用の説明書）
└── README.md      # 人間用の説明書（テキスト版）
ファイル役割ひとこと
SKILL.md何を守るか明朝見出し・罫線と余白・数字には出典 などのルール
template.css / parts.cssどう見えるか色を差し替えるのは先頭の:rootトークンだけ
snippets.htmlどう書くか部品ごとのコピペ用HTML+演出スクリプト
gallery.htmlどう見えるはずか見た目の正本。部品を追加したらここにも見本を足す（3点セット更新の掟）
見た目の正本は gallery.html。部品を追加・変更したら template.css（実体）・snippets.html（雛形）・gallery.html（見本）の3点セットで更新する — CSSだけ直すのが典型的な漏れ方。
03

使い方

頼み方・ブランド色の差し替え・更新の流れ

ふだんの頼み方

  • 「この調査結果を、いつものデザインでHTML資料にして」
  • 「このページをデザインシステムに合わせて刷新して」

新しい案件で使う時 — ブランド色の差し替え

その案件のロゴかファビコンをClaudeに渡して「このロゴの色でこの様式を使って」と言うだけ。鍵は原色をそのまま使わないこと。

×原色をそのまま差し色に

ロゴの原色（例: #F95320）は画面で強すぎて、誌面の静けさが壊れる。

○焦がしトーンに落とす

彩度を落とし暗めに寄せた色（例: #B8532F）を--accentに。役割色も同じく低彩度で揃える。

デザインを変えたくなった時 — 更新の流れ

1キャンバスで検討「デザインキャンバスで見たい」と頼む
2スキルに反映「スキルに反映して」で3点セット更新
3ページに移植「全ページに反映して」で既存資料へ
  • 更新は template.css（実体）→ snippets.html（雛形）→ gallery.html（見本）の3点セット+SKILL.mdの部品リスト。リポジトリに同梱している案件では、更新後にリポジトリ側へコピーする
04

社内展開

配る=フォルダをコピーする
置き場所効く範囲向いている使い方
~/.claude/skills/その人の全案件個人の標準装備にする
リポジトリ/.claude/skills/そのリポジトリを開いた人全員チーム展開はこちら。gitで共有され、pullした人に自動で配られる
 
# チーム展開の手順（例: RINCLEリポジトリ）
mkdir -p .claude/skills
cp -r ~/.claude/skills/html-doc-design .claude/skills/
git add .claude/skills
git commit -m "docs: HTML資料デザインシステムをスキルとして同梱"
個人版とリポジトリ版が両方ある場合、そのリポジトリ内ではリポジトリ版が優先される。
正本: README.md（同フォルダ・md更新時はこのHTMLも同期すること）
