# html-doc-design スキルの説明書

クライアント向けHTML資料を「誌面エディトリアル様式」で作るためのClaude Codeスキル。
この説明書は、スキルの中身がどうなっているか・どう使うか・社内にどう配るかをまとめたもの。

## そもそもスキルとは

Claude Codeの「スキル」= **ただのファイルの束**。`~/.claude/skills/<スキル名>/` にフォルダを置くだけで登録され、サーバー登録や設定画面は一切ない。

動く仕組みは3段階:

1. `SKILL.md` 冒頭の **description（説明文）だけは、どの案件でClaudeを開いても常に見えている**（名刺のようなもの）
2. 「HTML資料を作って」「デザインを統一して」など該当する依頼が来ると、Claudeが自分でこのスキルを開き、`SKILL.md` の本文（ルール）が読み込まれる
3. 本文に「template.cssとsnippets.htmlを読め」と書いてあるので、残りのファイルも必要な時だけ読まれる

つまり普段は説明文1行分しか場所を取らず、必要な時だけ全部載る省エネ構造。確実に発動させたい時はチャットで `/html-doc-design` と打つ。

## 中身のファイルと役割

```
~/.claude/skills/html-doc-design/
├── SKILL.md       … ルールブック。原則11箇条+ページ構造+スライド規格+検証手順
├── template.css   … 全部品のCSS。カラートークン・ヒーロー・章ナビ・表・チャート・
│                     スイムレーン・スライド枠・演出まで（コピーして使う）
├── snippets.html  … 各部品のHTML雛形集（コピーして使う）。スクリプト2種も収録
└── README.md      … この説明書（Claudeは読まない。人間用）
```

- **SKILL.md** … 「何を守るか」。明朝見出し・罫線と余白・影は浮遊部品のみ・数字は明朝の英数字・数字には出典、など
- **template.css** … 「どう見えるか」。`:root`のトークン（紙・墨・焦がしオレンジ・罫線2種・役割色5色）を先頭に集約してあり、**色を差し替えるのはここだけ**
- **snippets.html** … 「どう書くか」。部品ごとのコピペ用HTML

見た目の正本（ビジュアルで確認できる版）は Claude Design のキャンバス **「RINCLE デザインシステム」**（全10シート: 基礎/入力と操作/ナビ/入れ物/フィードバック/データ表示/チャート/資料部品/図解/スライド部品）。

## 使い方

### ふだんの使い方
Claude Codeでそのまま頼むだけ:
- 「この調査結果を、いつものデザインでHTML資料にして」
- 「このページをデザインシステムに合わせて刷新して」
- 効かない時は `/html-doc-design` を打ってから頼む

### 新しい案件で使う時（ブランド色の差し替え）
1. その案件のロゴかファビコン画像をClaudeに渡す
2. 「このロゴの色でhtml-doc-designの様式を使って」と言う
3. Claudeが原色を実測 →**彩度を落とした「焦がしトーン」を導出**して `--accent` に設定する（原色をそのまま使わないのがこの様式の鍵。RINCLEの例: 原色 #F95320 → 焦がし #B8532F）

### デザインを変えたくなった時（更新の流れ）
1. 「デザインキャンバスで見たい」と頼む → Claude Designのキャンバスで視覚的に検討・手で微調整
2. 方向が決まったら「スキルに反映して」と頼む → Claudeがこの3ファイルを書き換える
3. リポジトリ側の既存ページがある場合は「全ページに反映して」で移植

アーティファクト（キャンバス）をスクレイピングする必要はない。キャンバスの元データは作業ファイルとして手元にあるので、そこから抽出して3ファイルを書き換えるだけ。

## 社内展開のやり方

スキルはただのフォルダなので、**配る=フォルダをコピーする**。置き場所で効く範囲が変わる:

| 置き場所 | 効く範囲 | 向いている使い方 |
|---|---|---|
| `~/.claude/skills/html-doc-design/` | その人の全案件 | 個人の標準装備にする |
| リポジトリの `.claude/skills/html-doc-design/` | そのリポジトリを開いた人全員 | **チーム展開はこちら**。gitで共有され、pullした人に自動で配られる |

チーム展開の手順（例: RINCLEリポジトリ）:

```bash
mkdir -p .claude/skills
cp -r ~/.claude/skills/html-doc-design .claude/skills/
git add .claude/skills && git commit -m "docs: HTML資料デザインシステムをスキルとして同梱"
```

これでリポジトリをpullした山本さんのClaude Codeにも同じスキルが出る。個人版とリポジトリ版が両方ある場合、そのリポジトリ内ではリポジトリ版が優先される。
